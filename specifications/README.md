Thought it might be worth documenting AI usage here.

In general, my process is:

1. Brainstorm what I want to create.
2. Write a specification.
3. Have Claude implement the specification.
4. Review the implementation line-by-line, making edits or asking Claude to fix things.

For more involved tasks, I replace step (2) with the plan feature provided by Claude to guide implementation upfront.

The other files in this directory are records of my specifications.
